## Story

Como curador de conteúdo do Pule Pule, quero simplificar as competências de 24 (12 gestão + 12 comportamentais) para **12 competências comportamentais** com **36 comportamentos práticos** distribuídos em 12 meses — tornando a jornada mais focada, coerente e executável para os jovens.

---

## Acceptance Criteria

- [x] Apenas 12 competências comportamentais (CC01–CC12) no banco
- [x] 36 comportamentos (missões), 3 por competência, 1 por mês
- [x] Competências redistribuídas: 3 por fase (fases 1–4)
- [x] Contextos válidos: `pessoal`, `casa`, `escola`, `amigos` (alinhado com `MissionContext`)
- [x] Campo `example` nas missões com exemplo prático real
- [x] Campo `code` nas competências (CC01–CC12)
- [x] XP escalonado por fase: Fase1=50-70, Fase2=70-90, Fase3=90-110, Fase4=110-150
- [x] `database.ts` atualizado: `CompetencyCategory = 'behavioral'` (sem `'management'`)
- [x] `competencies/page.tsx` exibe "12 Competências" e "36 comportamentos"
- [x] Migration 008 aplicada no Supabase (producao)
- [x] Testes de regressão nas telas de journey e competencies

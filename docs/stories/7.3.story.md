# Story 7.3 — Refinamentos de UX Mobile

**Status:** Done
**Branch:** main
**Criada por:** @sm
**Data:** 2026-05-08

---

## Story

Como teen acessando o Pule Pule pelo celular, quero que todas as telas funcionem perfeitamente em mobile — com navegação fluida, sem delay de toque e sem comportamentos indesejados de scroll ou seleção de texto.

---

## Acceptance Criteria

- [x] Navegação por bottom tabs responsiva e touch-friendly (mobile nav já existia)
- [x] Área de toque dos nós do JourneyPath: 64×64px (w-16 h-16) — acima do mínimo de 44px
- [x] Tap highlight nativo removido (`-webkit-tap-highlight-color: transparent`)
- [x] Delay de 300ms eliminado em todos os botões/links (`touch-action: manipulation`)
- [x] Rubber-band scroll vertical desabilitado (`overscroll-behavior-y: none`)
- [x] Feedback tátil `active:scale-95` nos nós do JourneyPath (available, in_progress, completed)
- [x] `select-none` nos nós do JourneyPath — evita seleção acidental de texto no long-press
- [x] `select-none` + `active:scale-95` no bottom nav da Sidebar
- [x] Viewport já configurado: `width=device-width`, `initialScale=1`, `userScalable=false`
- [x] Formulários com inputs e textareas funcionais no teclado virtual mobile

## Dev Notes

- `touch-action: manipulation` elimina o delay de 300ms sem quebrar scroll — mais seguro que `touch-action: none`
- `overscroll-behavior-y: none` no html+body previne o efeito elástico do iOS que causa UX confusa
- `-webkit-tap-highlight-color: transparent` aplicado globalmente em buttons, a, inputs, textareas, selects

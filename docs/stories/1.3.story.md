# Story 1.3 — BehaviorModal e JourneyPath Refactor

**Status:** InProgress
**Branch:** main
**Criada por:** @sm
**Data:** 2026-05-06

---

## Story

Como teen do Pule Pule, quero que o modal de comportamento mostre a descrição em 3ª pessoa, valide minha narração via IA antes de submeter, e que o caminho da jornada reflita visualmente o progresso por competência — tornando a experiência mais imersiva e educativa.

---

## Acceptance Criteria

- [x] Modal exibe descrição do comportamento em 3ª pessoa (não 1ª pessoa do banco)
- [x] Campo de narração com mínimo de 20 caracteres
- [x] Validação via IA (`/api/missions/[id]/validate-narration`) antes de marcar como `in_progress`
- [x] Se narração >= 20 chars ao clicar "Iniciar", vai direto para validação (sem etapa dupla)
- [x] Feedback de rejeição da IA exibido com orientação ao teen
- [x] Estado `approved` exibe tela de celebração com auto-close (2.5s)
- [x] `JourneyPath` agrupa comportamentos por competência com `competencyCode`
- [x] Snake path com posições `center/right/center/left` por fase
- [x] Regra estrita: apenas `approved` desbloqueia o próximo comportamento
- [x] `unlock.test.ts` cobre todos os status de desbloqueio
- [ ] Testes unitários para `toThirdPerson()` function

# Story 1.1 — Admin Panel

**Status:** InProgress
**Branch:** main
**Criada por:** @sm
**Data:** 2026-05-06

---

## Story

Como admin do Pule Pule, quero ter um painel de administração completo para visualizar métricas da plataforma, gerenciar usuários e acompanhar envios — sem precisar acessar o Supabase diretamente.

---

## Acceptance Criteria

- [x] Rota `/admin` protegida por role `admin` no middleware
- [x] Layout dedicado para admin com navegação própria (`AdminLogoutButton`)
- [x] Página de visão geral (`/admin`) com stats: total teens, mentores, pais, aprovações, pendentes
- [x] Lista dos últimos 8 envios com status colorido
- [x] Top 5 teens por XP com nível e índice de autonomia
- [x] Página de envios (`/admin/envios`) — lista de missões submetidas
- [x] Página de ranking (`/admin/ranking`) — teens ordenados por XP
- [x] Página de usuários (`/admin/usuarios`) — lista com role e ação de exclusão
- [x] API route `DELETE /api/admin/users/[id]` — chama `admin_delete_user` RPC
- [x] Componente `DeleteUserButton` com confirmação e feedback
- [x] Redirect automático de admin para `/admin` (não-admin bloqueado via middleware)
- [ ] Testes de autorização para `DELETE /api/admin/users/[id]`

## Dev Notes

- PDF via `window.print()` — sem biblioteca externa, funciona em todos os browsers
- Classes `print:hidden` escondem elementos de navegação na versão impressa
- Classes `print:block` exibem cabeçalho e rodapé apenas na impressão
- Parent resolve teen_id via `parent_teen` table; mentor tenta o mesmo
- Teen vê o próprio relatório
